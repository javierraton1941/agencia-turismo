# YAHUARCOCHA VIVA

## Nombre del proyecto
Portal web de la agencia turística ficticia **Yahuarcocha Viva**.

## Nombre del estudiante
Luis Javier Moreta A.

## Destino turístico asignado
Ibarra / Yahuarcocha - Imbabura, Ecuador.

## Descripción del proyecto
Sitio web informativo y responsive para promocionar los atractivos naturales, culturales, gastronómicos y recreativos de Ibarra y Yahuarcocha. Incluye seis lugares turísticos, cuatro paquetes referenciales, información de alojamiento, restaurantes, transporte, artesanías y eventos locales, además de un formulario HTML5 de contacto.

## Tecnologías utilizadas
- HTML5 semántico y accesible.
- CSS3 con variables, selectores, pseudo-clases, box model, Flexbox, Grid y media queries.
